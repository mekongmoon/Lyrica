# v2 Lean API

The v1 endpoint `/lyrics/` keeps its response format. `/v2` adds a compact
schema, ETag/304 support, explicit sync tiers, and small error envelopes. Both
are served by the same deployment and share one lyrics cache; there is no
separate v1 host or port.

!!! warning "Beta"
    `/v2` is in beta until `v2.0.0`. The response contract may still change
    and is frozen in [#14](https://github.com/mekongmoon/Lyrica/issues/14).

## `GET /v2/lyrics`

| Parameter | Default | Description |
|---|---|---|
| `artist` | required | Artist name |
| `song` | required | Song title |
| `tier` | `line` | `plain`, `line`, `word`, or `syllable` |
| `allow_lower` | `true` | Serve the best available lower tier when the requested tier is missing |
| `lite` | `false` | Omit `artist`, `title`, `dur`, and `src` |
| `fields` | — | Comma-separated top-level fields to keep |
| `translate` | `false` | Translate with the instance's Groq key |
| `romanize` | `false` | Romanize/transliterate |
| `lang` | `en` | Target language |
| `fast` | `false` | Query providers in parallel and return the first valid match |

### Line-level example

```bash
curl "http://127.0.0.1:9999/v2/lyrics?artist=Coldplay&song=Yellow&tier=line"
```

```json
{
  "v": 2,
  "src": "lrclib",
  "tier": "line",
  "artist": "Coldplay",
  "title": "Yellow",
  "dur": 267000,
  "lines": [[35660, "Look at the stars"], [38460, "Look how they shine for you"]]
}
```

### Word and syllable levels

Word and syllable timing comes from **Lrcmux** and **Apple Music**, which are
tried first. If neither has the requested tier:

- `allow_lower=true` (default) returns the best lower tier available from
  **any** source, for example line-level lyrics from LRCLIB. The `tier` field
  says what you got.
- `allow_lower=false` returns `404 {"err":"tier_unavailable","tier":"<best available>"}`.

A failed upgrade is remembered for a while, so repeated requests for a tier
that does not exist do not call providers again. (Whether word requests should
instead be limited to Lrcmux and Apple Music is open in
[#40](https://github.com/mekongmoon/Lyrica/issues/40).)

```json
{"lines": [[35660, "Look at the stars", [[35660, "Look"], [37200, "at"], [37700, "the"]]]]}
```

Syllable lines append one more level:

```json
{"lines": [[35660, "Look", [[35660, "Look", [[35660, "Lo"], [35800, "ok"]]]]]]}
```

Rules:

- Lines are `[start_ms, text]`. There is no per-line `id` and no `end_time`;
  clients derive the end from the next line.
- Integers are milliseconds.
- Nulls and false defaults are omitted.
- Errors are tiny: `{"err":"not_found"}`.

### Status codes

| Code | Meaning |
|---|---|
| `200` | Success |
| `304` | Unchanged (`If-None-Match` matched the ETag) |
| `400` | `missing_artist_or_song` or `bad_tier` |
| `404` | `not_found` or `tier_unavailable` |
| `500` | `internal` |
| `502` | `ai_failed` (translation/romanization error) |
| `503` | `upstream_unavailable` (providers errored, not a clean miss) or `ai_unavailable` (no Groq key) |
| `504` | `timeout` |

Every successful response carries an `ETag` and an `X-Cache: HIT|MISS` header.
Send the ETag back as `If-None-Match` to get a bodyless `304`.

## `GET /v2/capabilities`

Reports the supported tiers, the providers enabled on this instance, AI
availability, and whether responses are compressed (currently always `true`;
see [#17](https://github.com/mekongmoon/Lyrica/issues/17)).

```json
{"v": 2, "tiers": ["plain", "line", "word", "syllable"], "providers": ["genius", "lrclib", "lrcmux", "megalobiz", "netease", "youtube"], "ai": false, "byok": false, "compression": true}
```

## `GET /v2/health`

Reports per-provider breaker state, quota tokens, success/error/not-found
counters, p50/p95 latency, singleflight stats, negative-cache stats, and cache
stats. Provider failures are logged at `WARNING` with the provider name and
reason.

This endpoint is currently public. Whether to trim it or require the admin key
is open in [#15](https://github.com/mekongmoon/Lyrica/issues/15). Use `/health`
for liveness checks.

## Provider safety

Every provider call passes through one choke point (`src/core/providers.py`):

- Token bucket per provider, seeded from `.lyrica.config` RPM values and
  overridable with `LYRICA_PROVIDER_<NAME>_RPM`.
- Circuit breaker: opens after 5 consecutive transport failures, cools down
  for 30 seconds, then allows a single probe and requires two good probes
  before closing.
- Per-loop bulkhead (`LYRICA_PROVIDER_CONCURRENCY`, default 8).
- Metrics: latency, success, errors, not-found, rejected.

A provider can be disabled with `LYRICA_DISABLED_PROVIDERS=genius,apple_music`.
